# Pixel Palace: Brand Portfolio Website

Single-page, responsive brand site for **Pixel Palace**, a gaming zone in Karachi.
Built with plain HTML, CSS and a little JavaScript. No build step.

## Files

| File | Purpose |
|---|---|
| `index.html` | Page content and structure |
| `style.css` | Brand styling and responsive layout |
| `script.js` | Mobile menu, scroll effects, booking form |
| `logo.svg` | Pixel-castle logo (also used as favicon) |

## Brand

- **Name:** Pixel Palace
- **Tagline:** Level up your day.
- **Colours:** Violet `#8b5cf6`, Cyan `#22e4ff`, Pink `#ff4fa3`, Amber `#ffc83d` on deep navy `#0a0718`
- **Fonts:** Press Start 2P (headings), Outfit (body)

## Publish on GitHub Pages

1. Create a new **public** repository on GitHub, for example `pixel-palace`.
2. Upload all four files to the repository root (Add file, then Upload files), or push them:
   ```bash
   git init
   git add .
   git commit -m "Pixel Palace website"
   git branch -M main
   git remote add origin https://github.com/<your-username>/pixel-palace.git
   git push -u origin main
   ```
3. In the repository, open **Settings, then Pages**.
4. Under **Build and deployment**, set Source to **Deploy from a branch**, choose branch **main** and folder **/ (root)**, then Save.
5. Wait a minute or two. Your live site will be at:
   `https://<your-username>.github.io/pixel-palace/`

- Repository: `https://github.com/<your-username>/pixel-palace`
